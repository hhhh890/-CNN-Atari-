## 强化学习实践报告：基于CNN的吃豆人游戏智能体

### 一、 实验背景与目标
本次实践基于Gymnasium强化学习框架，旨在通过构建并训练一个基于卷积神经网络（CNN）的智能体，解决Atari吃豆人游戏。通过阅读Gymnasium官方文档，我们深入理解了强化学习的标准训练流程：包括环境实例化、状态观测、动作采样、奖励反馈以及网络参数更新。本次实验的核心目标是实现一个能够有效提取游戏画面特征并进行决策的深度Q网络，最终训练出接近满分的智能体。
### 二、 算法与网络结构设计
为了处理Atari游戏的高维像素输入，本实验采用深度Q网络（DQN）架构。参考课程PPT中的指导，我在 `QNetwork` 中设计了CNN特征提取器
**设计说明：**
1. **状态输入**：网络输入形状为 `4*84*84`，采用4帧连续画面堆叠，使智能体能够感知游戏中幽灵和豆子的运动趋势。
2. **特征提取**：采用经典的Atari CNN架构，三层卷积层逐步提取空间特征并降低维度（8x8 stride 4 -> 4x4 stride 2 -> 3x3 stride 1），有效捕捉游戏画面中的关键实体。
3. **前向传播归一化**：在 `forward` 函数中，对输入 `x` 除以 `255.0` 进行归一化，这是加速网络收敛、稳定训练的关键步骤。
4. **动作输出**：最终全连接层输出维度与 `env.single_action_space.n` 一致，直接预测各个离散动作的Q值。
### 三、 训练流程与环境交互
在Gymnasium框架下，训练流程严格遵循标准的强化学习循环：
1. **环境初始化**：使用Gymnasium创建Atari环境，并配置帧堆叠和图像预处理Wrapper。
2. **动作选择**：采用 $\epsilon$-greedy 策略平衡探索与利用。智能体根据当前状态 $s$ 输入Q网络，选择Q值最大的动作 $a$。
3. **环境步进**：执行动作 $a$，从环境获取下一状态 $s'$、奖励 $r$ 及终止标志 `done`。
4. **经验回放**：将 $(s, a, r, s', done)$ 五元组存入经验回放池，打破数据相关性。
5. **网络更新**：从回放池中随机采样Batch数据，计算目标Q值与当前Q值的均方误差（MSE），通过反向传播更新网络参数。
### 四、 实验结果与分析
经过充分训练，智能体在吃豆人游戏测试中取得了 **2390分** 的优异成绩（满分2400分），趋近于完美策略。
**结果分析：**
* **高得分的成因**：智能体能够准确区分豆子、大力丸与不同颜色的幽灵。通过4帧堆叠，智能体学会了预判幽灵的移动轨迹，在规避危险的同时最大化吃豆效率。在吃到大力丸后，网络能够迅速改变策略，主动追击处于恐慌状态的幽灵以获取高额奖励。
* **网络稳定性**：`x / 255.0` 的归一化操作配合ReLU激活函数，有效避免了梯度消失或爆炸问题，使得在长时序训练中Loss能够平稳下降。
* **特征提取有效性**：三层卷积网络成功将高维像素信息降维提炼，证明了课程PPT中所提供的CNN结构在Atari游戏视觉控制任务中的卓越表现。
